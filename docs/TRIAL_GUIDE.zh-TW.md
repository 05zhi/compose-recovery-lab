# 獨立試用與回饋

此文件是待執行的試用流程，不代表已訪談或取得使用者回饋。尚未聯絡任何外部人員。

邀請至少兩名試用者在各自專用 Linux 測試環境依 OPERATIONS.zh-TW.md 重現，不提供正式資料。每人記錄：主機／Docker／Compose 版本、安裝耗時、首次成功或錯誤、報告是否容易區分資料失敗與清理失敗、文件需補充的步驟。

依序執行完整文件備份、缺附件備份、完整庫存備份、SIGKILL 後 recover 與 retry。核對必要檢查、cleanup 結果及沒有演練資源殘留。不要回傳生成的 compose.json、憑證、正式 dump 或未遮蔽日誌。

回饋格式：

```text
日期／匿名試用者代號：
系統與工具版本：
使用 commit：
依文件成功重現的步驟：
卡住的命令與遮蔽後訊息：
預期／實際行為：
是否理解抽樣、未檢查範圍與隔離限制：
建議修正與優先順序：
```

取得回饋後新增 issue／修正／對應測試，再更新驗收紀錄。沒有真實回覆前不得將此條件標記完成。3–5 位需求訪談、與既有產品比較及第二人獨立重現同樣需要真實參與者與可追溯紀錄。
